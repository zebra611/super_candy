# 48 · 官方热线 4006180092 与档案浏览

2026-11-11 深夜。用户给了两份官方材料（QA.xlsx 三个 sheet、场景.xlsx 四个 sheet），两件事：
「我目前好像没看到你给了京东人工客服的电话」；「除了随机选档案，希望可以按一个按钮分类查看所有示例数据，然后可供挑选的进行客服对话」。

## 一、热线：官方口径里一直有，我们一直没给

对照结果（证据确凿）：

- **QA.xlsx「驳回话术」sheet**：56 行驳回话术里 **30+ 条**结尾是「如有疑问可联系4006180092」；
- **场景.xlsx**（四个 sheet 共 700+ 行）：驳回话术的统一结尾是
  「**如有疑问您可以电话联系：4006180092，我们将竭诚为您服务！**」；
- 场景汇总的关单总原则：电话关单的场景需外呼告知驳回原因与处理方案——热线就是官方留给商家的兜底出口。

我们此前的收线/转人工话术只有「稍后专员会用官方号码再联系您」，号码永远缺席。接入三处：

1. **官方 QA**：`config/mock/qa.json` 新增 QA-HF-028「人工客服电话是多少」→
   「如有疑问您可以电话联系：4006180092，我们将竭诚为您服务。」客户问
   「你们客服电话是多少 / 怎么联系人工」都能命中（lookup_qa ≥4 字片段闸实测通过）。
2. **收线话术**（两份场景包 + 代码默认值同步）：转人工 `reply_handoff`、
   CONFIRM 三条收线（没听懂两次 / 提问答不上两次 / 含糊三次）、求助升级
   `reply_help_escalate`（加「着急的话也可以直接拨打商家热线 4006180092」）与
   `reply_help_bye`、语言不通收线。措辞统一为
   「如有疑问，您也可以拨打京东商家热线 4006180092。」
3. 右栏「驳回话术」展示本来就走官方资料包结构化数据，已带热线。

冻结语义不变：这些话术全部走 `_finish`（end_reason 有值）或 `_FREEZE_INTENTS`，模型碰不到——热线号码是承诺，不许改写。

## 二、档案浏览：151 家按类目挑

原入口只有「随机一份」。现在「① 先选对象」里两个按钮：**随机一份 / 全部档案**。

- 后端：`/api/applications`（151 条可电话外呼档案的展示字段——与随机同一个池，
  京麦驳回档案进不了完整对话，不放进列表误导人）；`/api/company/get?application_id=`
  按单号取完整档案（含补全部件，口径与随机预览一致）。列表**不含**身份证号/
  统一社会信用代码，点选某一家才单条取全。
- 前端：右栏「外呼目标」面板顶部加浏览框——类目 chips（全部/医药保健/图书文娱/
  家居日用/家用电器/数码3C/服饰鞋包/生鲜/美妆/汽车用品/跨境…）+ 列表
  （公司名 + 品牌 · 类目 · 驳回原因）。列表拉一次，切换类目纯前端过滤；
  点某一行 → 完整档案卡 + 顶部「本次目标」牌出现 → 点「文字对话」即以该档案开场。
  通话中浏览按钮随其他入口一起锁住。
- 冒烟：`scripts/ui_smoke.mjs` 更新为 13 条（浏览加载/筛选/选中/目标牌/收起/
  与随机不冲突/对话/挂断/事件链），系统 Edge 无头全过；截图人工核对布局正常。
