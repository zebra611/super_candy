# 46 · 那句「您回一个字也行」，和前端 PR 的操作逻辑

> 触发：用户圈着截图里的一句「……缺了品牌方到一级经销商的逐级授权文件。
> 您回一个字也行。」问哪里奇怪、怎么改；同时让评审 `feat/ui-simplify`
> 这份重做了前端的 PR，重点是操作逻辑。

## 一、那句话的四个毛病

1. **同义反复**：「授权链路不完整」就是「缺了品牌方到一级经销商的逐级授权文件」，
   两个半句一件事说两遍，还写成"因为 A，缺了 A 的表现"。
2. **两句各说各话**：前半句是陈述（坏消息），后半句突然索要回应，中间没有任何连接。
3. **"回一个字"没有可执行答案**：驳回通知里客户回"哦/嗯/好"哪个都推进不了流程；
   客服真正想问的是"听明白没有"，却给了个没法回答的选项。
4. **"也行"带着预设**（"我知道你懒得说"），像推销在求人，不像官方审核；
   而且客户刚回了个"哦"，已经表示听到了，再要一个字等于没听见。

**改法（用户选了"推进下一步"）**：后半句换成「这一步您清楚怎么补吗？」——
陈述 + 一个可执行的确认问题。

## 二、为什么这句还会出现：词表永远差一条

这句尾巴是 persona 的 quiet 后缀，靠 `_SKIP_SUFFIX_MARKS`（驳回/材料/授权书/后台…）
拦截。模型这轮说的是「没通过 / 授权文件」，一个都没命中。这已经是第三轮
用词表打地鼠。**这次不再加词**，改成按**后缀意图**分流：

| 后缀类型 | 讲本单事实的句子后面 | 判据 |
|---|---|---|
| 讨回应型（默认，如急脾气的「我就不多说了。」） | 一律不加 | `_FACT_MARKS`（加了"没通过/未通过/不通过/授权文件/授权链路"） |
| 推进型（`kind=advance`，如 quiet 的「这一步您清楚怎么补吗？」） | **正是该加的地方** | 只看结构：有问号 / 在要信息 / 在收尾 / 已在讨回应 → 不加 |

quiet 的规则同时按阶段收敛：只剩 NEED/OFFER/CONFIRM 三条，不再有无差别的 `"*"`——
核身阶段不会莫名其妙问"怎么补"。优化器候选池同步换掉，防止它把讨回应的话
再"优化"回来。性格基线 p9 → p10（12 通逐字未变）。

```
quiet+OFFER  讲事实句 → …逐级授权文件。这一步您清楚怎么补吗？   ← 截图那句的新样子
quiet+IDENTITY        → 原句不动（没有该阶段规则）
impatient+OFFER 讲事实 → 原句不动（讨回应型，行为不回归）
```

## 三、前端 PR 评审与重构

`feat/ui-simplify`：web/index.html +1180/−195。**方向对**（三入口 + 对话主位 +
右侧五页签），DOM 元素一个没删。但操作逻辑看不懂的**根因是结构**：
状态靠"看"不靠"算"——3 个 MutationObserver 盯着 `btnEnd.disabled`、
`phaseLine` 文本、档案卡 `display` 反推状态，另有 7 处直接改按钮。
纯文字模式的状态行还得靠观察器补一句"文字对话进行中"，而 `startCall`
里已经为同一件事手写过一遍。

### 评审抓到的硬伤（按影响排序）

1. **挂断后事件链是死路**：提示条说「事件链标签里有完整记录」，但 `end_call`
   会把服务端会话删掉，挂断后点「刷新」永远 UNKNOWN_SESSION。
2. **两通对话混在一个框里**：再开一通不清屏。
3. **空 Enter = 一次沉默轮**：高频键上绑了个隐式语义，误按消耗一轮、还推进 no_answer。
4. 三入口等权，两个"开始"一个"选对象"，选完档案没有常驻提示锁了哪家。
5. `window.__textMode/__askTarget` 全局变量 + 两套绑定并存（onclick 与 addEventListener）。
6. 纯文字模式下「暂停聆听」永远点不动却一直显示。
7. 提示条"第 N 步"与进度条 7 阶段两套编号对不上。
8. 训练回放/自进化（离线评测）与外呼目标/指标/事件链（本次通话）混在一排页签。
9. `startCall` 的 fetch 没有 try——服务没起来时页面毫无反应。

### 重构（已在分支上完成，`a164c8e`）

一处理算：`UI_STATES` 5 态（idle/text/voice/paused/closed），事件只改 `S.ui`
调 `render()`，删掉全部观察器与全局 flag。上表 9 条全部修掉：

- 事件链：挂断瞬间（会话还活着时）先拉一份快照存 `S.lastEvents`，之后「刷新」用快照；
- 第二通开始清屏；空发送拆成独立「模拟不说话」按钮，主发送空值不发；
- 三入口分「① 先选对象 / ② 再开始对话」两组 +「本次目标」常驻目标牌
  （注意：桌面端 `.ctrl` 未通话时整行隐藏，目标牌不能放那儿——第一次就放错了）；
- 纯文字模式隐藏「暂停聆听」；提示条改「下一步：」；页签分「本次通话/离线评测」两组；
- `startCall` 包 try/catch；拿不到麦克风自动退回文字模式。

**验证**：`scripts/ui_smoke.mjs`（playwright + 系统 Edge，23 条断言）全过——
冒烟第 ⑦ 步还抓出一个我自己引入的回归（挂断后 `.compact` 不退回，
用户找不到"再打一通"的按钮），已修。`node --check` 过。
