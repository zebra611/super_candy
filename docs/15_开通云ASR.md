# 开通云 ASR：从注册到"能听懂你说话"

> 目标：让 `web/index.html` 里说的一句话，真的变成文字送进状态机。
> 前置条件：S1 已完成（音频已经是 16kHz PCM 送到服务端），只差最后一步识别。
> 预计耗时：**40 分钟**，其中 30 分钟是注册与实名。

---

## 1. 先想清楚：为什么选阿里云百炼

| | 阿里云百炼 | 腾讯云 | 讯飞 |
|---|---|---|---|
| 实时识别单价 | 约 0.86 元/小时 | 约 1.8 元/小时 | 约 2.0 元/小时 |
| 一个 key 能不能同时做 LLM | **能**（通义千问同账号） | 能 | 不能（另开） |
| 中文效果 | 好，支持热词 | 好 | 好 |
| 文档友好度 | 好 | 中 | 中 |

**决定性理由**：我们的对话编排（佟欣那层）迟早也要接大模型，同一个账号一把 key 能同时搞定识别、合成、大模型三件事，少注册两次、少管两个密钥。价格也是三家里最低的。

> 下面的步骤只针对百炼。如果学校/导师已经给了别的账号，告诉我换哪家，适配层不用重写。

## 2. 注册与实名（约 30 分钟，只有这一步没法省）

1. 打开 **https://www.aliyun.com** → 注册（手机号 + 验证码）。
2. **必须实名认证**，否则 API 一律调不通，报的错还很含糊。
   路径：控制台右上角头像 → 「实名认证」→ 个人认证 → 支付宝扫码或刷脸，通常 2 分钟过。
3. 学生的话顺手做「学生认证」，部分产品有折扣，但**识别这块的免费额度与学生身份无关**，别指望它。

**常见卡点**：实名没通过就去建 key，建得出来、但每次调用都 401，很容易误判成"代码写错了"。这就是为什么下一步第一件事是验 key。

---

## 3. 开通百炼并拿到 key

1. 打开 **https://bailian.console.aliyun.com** （大模型服务平台「百炼」）。
2. 首次进入会要求开通服务，勾选协议、点开通。免费，不开通建不了 key。
3. 点右上角**头像** → **API-KEY 管理** → **创建新的 API Key**。
4. 生成的是 `sk-` 开头的一串。**只显示这一次**，关掉就再也看不到，丢了只能删掉重建。
   → 立刻粘贴到下面第 4 节说的文件里，别先存微信。

顺手看一眼额度：控制台左侧「费用与成本」或模型详情页会显示免费额度与已用量。**免费额度经常调整，以控制台显示为准**，别信任何文章里的数字（包括这份文档）。

---

## 4. 把 key 放进项目（关键：不能进仓库）

项目约定：**业务配置在 `config/scene.json`（要提交），密钥在 `config/secrets.json`（不提交）**。

项目根目录下执行（Windows 用 `启动.bat` 那个 Python，别指望系统 `python`）：

```bat
copy config\secrets.example.json config\secrets.json
```

然后用记事本或 VS Code 打开 `config/secrets.json`，把这一行改成你的 key：

```json
"dashscope_api_key": "sk-你的真实key"
```

**为什么单独一个文件**：

- `scene.json` 是要提交的（换场景靠它），密钥写进去会被 git 永久记住，删掉也还在历史里；
- `secrets.json` 已被 `.gitignore` 排除，`git status` 里根本不会出现；
- 云端部署没有这个文件，所以代码同时支持环境变量 `DASHSCOPE_API_KEY`，**环境变量优先**。

**三条红线**：

1. 不要发群里、不要贴进聊天、不要截图带 key 的窗口；
2. 不要写死在 `.py` 里；
3. 万一泄露，去控制台把那把 key 删掉重建——比"改密码"快，也不影响别的。

---

## 5. 验证 key 到底能不能用（30 秒）

```bat
python scripts\check_key.py
```

它会分三步告诉你结论，而不是甩一个报错让你猜：

| 输出 | 含义 | 下一步 |
|---|---|---|
| `key 有效，模型 xxx 可用` | 全通了 | 进第 6 节 |
| `key 无效或没有权限（401/403）` | key 错、被删、或没实名 | 回第 2、3 节重拿 |
| `key 本身能用，但请求参数被拒（400）` | **鉴权过了**，只是模型名不对 | 去模型广场核对模型名 |
| `连不上 dashscope.aliyuncs.com` | 网络到不了，不是 key 问题 | 换热点/关代理再试 |

> 这个脚本特意把 **401** 和 **400** 分开：401 才是 key 的问题，400 说明 key 已经通过鉴权。分不清这两者，会白折腾一晚上。

## 6. 切换到云端识别

改 `config/scene.json` 里这一段：

```json
"asr": {
  "provider": "dashscope",          ← 从 placeholder 改成 dashscope
  "model": "paraformer-realtime-v2",
  "endpoint": "wss://dashscope.aliyuncs.com/api-ws/v1/inference",
  "language": "zh",
  "hints": ["张伟", "李娜", "延保", "京东", "订单号", "工单", "权益"]
}
```

重启服务（关掉黑窗口再双击 `启动.bat`）。页面上说话，`user_text` 就应该变成你真说的话，而不是那句固定的"（假识别）…"。

**回落规则**：`provider` 写了 `dashscope` 但没配 key 时，代码会自动退回占位识别，不会报错。这样队友 clone 下来、或者你去别的电脑演示，都不会因为少个文件就跑不起来。

## 7. 花多少钱，怎么防跑飞

按公开价格（2026-11，**以控制台为准**）：

| 项目 | 单价 | 说明 |
|---|---|---|
| `paraformer-realtime-v2` 实时识别 | **0.00024 元/秒** ≈ 0.86 元/小时 | 按音频时长计费，输出免费 |
| `fun-asr-realtime` | 0.00033 元/秒 ≈ 1.19 元/小时 | 新一代，噪声下更稳 |
| 录音文件识别 `paraformer-v2` | 0.00008 元/秒 ≈ 0.29 元/小时 | **便宜三倍，但不是流式** |

**本项目一笔账**（一通 2 分钟的电话，用户说 90 秒）：

```
90 秒 × 0.00024 = 0.0216 元 ≈ 2 分钱（只算识别）
```

加上合成与大模型，一通约 **5 分钱**。调试期每天测 40 次短句（每次 10 秒）≈ **1 元/天**。

**三个防跑飞的设置**：

1. **费用中心设预算提醒**：控制台 → 费用与成本 → 预算管理 → 设 50 元/月，超了发短信。别等月底看账单。
2. **代码里已有闸门**：`config/scene.json` 的 `budget` 段限制单通时长 300 秒、40 轮，超了自动收尾（`app.py` 的 `_budget_reason`）。
3. **前端别一直开着麦克风**：一轮说完就停采，页面关掉就释放。开着不说话也在按秒计费。

> 顺带纠正我早前给你的一个数字：`docs/05` 里写的"0.288 元/小时"是**录音文件识别**的价格，实时识别是它的 3 倍。总成本依然在"几块钱"量级，但不该拿错那个单价。

## 8. 常见坑（按踩到的概率排序）

| 现象 | 真实原因 | 处理 |
|---|---|---|
| 每次调用都 401 | 没做实名认证 / key 复制带了空格 / key 已重建 | 重拿 key，跑 `check_key.py` |
| 报"模型不存在" | 模型名写错，或该模型在你账号所属地域不可用 | 控制台「模型广场」核对；`paraformer-realtime` 系列目前仅华北2（北京） |
| 明明没说话也在扣费 | 实时识别按**音频流时长**计费，静音也算 | 后面 S3 上 VAD，把静音段掐掉再送 |
| 识别结果一堆错字 | 采样率不是 16k、或双声道当单声道 | S1 已按契约固定 16k/单声道，`audio_stream.sample_rate` 可核对 |
| 人多时排队/失败 | 共享并发通道有上限 | 演示前只在评委面前开一路，别压测 |
