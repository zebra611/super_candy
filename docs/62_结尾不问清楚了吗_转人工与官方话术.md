# 61 结尾不问「清楚了吗」：改问要不要转人工，结束语回到官方原话

11-13 第三轮反馈，三件事一起改：

1. 最后强调完不要再问「你清楚吗」一类的话；
2. 话术严格执行官方两张表；
3. 结束语之前要问一句是否需要转人工。

## 一、为什么「清楚了吗」必须换成别的问句

复述完问「这样讲清楚了吗」，功能上不是纯文案——它是**征集表态的信号**：

| 位置 | 作用 | 换掉之后会怎样 |
|---|---|---|
| `adversary._CONFIRM_PROMPT_MARKS` | 低压力画像据此如实回答 | 认不出问句 → 一律沉默，确认环节卡死 |
| `user_sim._ASK_PATTERNS["confirm"]` | 模拟客户据此给出 CONFIRM 动作 | 认不出 → 走 ACK/OFF_TOPIC，12 个画像 10 个不闭环 |
| `agent_free` 2c 闸 | 拦模型把「清楚了吗」说回去 | — |

11-13 第一次跑基线就是这个结果：**总 2/12**，所有 `goal=confirm` 的会话全部 `closed: false`。不是客服不会收尾，是模拟器听不见问句。把两处信号表换成「转接人工 / 转人工 / 帮您转接」之后，12/12 全闭环。

**所以这次不是把问句删掉，是换了一个问句**：复述完问「需要我帮您转接人工客服吗？」——
问的是要不要人接手，不是问客户懂没懂。客户答「清楚了」照样闭环（`confirm_yes_words` 不动），
答「不用了」也闭环（见下一节），答「要转人工」走 `_handoff`。

## 二、「不需要转人工」不等于「拒绝整改」

收尾问句换了，`flags["no"]` 就多了一种语义。旧逻辑只有一条路：

```
商家说「不用了」→ flags["no"] → _do_writeback(consent=False) → 工单记「商家拒绝」
```

但这通电话其实已经谈完了，商家只是不需要人接手。业务侧按「拒绝」跟进，等于把谈成的单记成没谈成。

`dialogue._no_handoff()` 把两种否定分开：

- `_NO_HANDOFF_MARKS`：不用转 / 不需要 / 不用了 / 自己弄 / 没别的事 / 就这样 …
- `_REJECT_FIX_MARKS`：不改 / 不补 / 不提交 / 不同意 / 放弃 …

命中前者且不含后者 → `consent=True`，正常闭环；后者仍记 `consent=False`。
这一支必须排在 `flags["no"]` **之前**，否则永远走不到。

## 三、结束语回到官方原话

官方「驳回话术（开头语+驳回话术+结束语）」那张表的结束语是：

> 感谢您的接听，祝您生活愉快，再见！

我们此前播的是「感谢您的配合，再见」，属于自造。这次统一：

- 两份场景包（`config/scene.json` 与 `config/scenes/pop_reject.json`，互为镜像）17 处；
- `dialogue.py` 里 8 处兜底默认值。

顺带修掉一个把官方句子劈开的写法：`_with_hotline()` 原来把热线插在「再见」之前，
于是「感谢您的接听，祝您生活愉快，再见！」变成「…祝您生活愉快。如果还有问题，直接打电话联系 4006180092。再见！」。
现在热线插在「感谢您的接听」**之前**——官方话术里热线本来也在这个位置（"如有疑问您可以电话联系：4006180092"）。

收尾句另加一道冻结：`_reply()` 里含「感谢您的接听 / 感谢您的配合」的句子不进改写层。
实测改写会把它压成「感谢接听。如果还有问题…」，官方口径就没了。

## 四、复述句也冻结

`must_say` 要的「复述」两个字，改写层会顺手删掉：

- 骨架：要做的事我复述一遍：备齐…，再重新提交。
- 改写后：备齐…，后台逐张上传后重新提交。（「复述」没了）

`_reply()` 增加 `_freeze_restate`：文本含「复述」时，`agent_free` 与 `nlg` 都不碰，骨架原话直接播。

## 五、话术执行情况（对着官方两张表核）

两张桌面表与仓库 `competition/官方资料包/` 的两份 xlsx **md5 完全一致**
（`e55cd53a…` / `9335d19b…`），所以核的是同一份数据。

| 检查 | 结果 |
|---|---|
| `config/kb_pop.json` 的 answer 能否逐字在官方单元格里找到 | 94/94 命中（0 条改写） |
| 电话单能否说出填满槽位的官方话术 | 151/151，同业务域替身 5 条（016/026/047/067/068，档案缺字段） |
| 京麦驳回单是否被配了电话话术 | 0 条（官方口径：京麦驳回关单不做强制回电限制） |
| 开场白 | 「您好，我是京东商家资质审核专员，请问您是{公司}这边吗？」与官方「请问您是（商家公司名/店铺名称）吗」一致 |

**京麦驳回这条单独说清楚**：官方表把它归为站内驳回、不强制回电，我们现在的处理就是
`official_script.script_for()` 见到 `close_mode == "京麦"` 直接不返回电话话术，
`IDENTITY` 阶段播「您这笔申请属于京麦驳回场景，按商家后台的站内指引补充材料即可」。
按官方表本身的口径，这里的处理是对的，本次不动。
