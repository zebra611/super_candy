2026-11-12 傍晚，用户连发六张线上通话截图，逐句指出话术问题。全部按真跑
（`app.handle_turn`）复现后再改，不靠猜。

1. 「啥意思，主语宾语都对不上」——`请问您是闻溪官方旗舰店吗？`
2. 「这个日期，建议你说一周内完成，不要有具体时间」——`2026-10-03前完成`
3. 「这明明是按顺序操作却要说你想搞哪一步，应该说您对哪步不是很清楚」
4. 「问补齐到哪，回答也是牛头不对马嘴」——回`您看这样解释清楚了吗？`
5. 「这几轮问答同样有问题」——`还有疑问`被当成"清楚了"，还串出别的场景的
   「同意 / 不需要」，最后误记 `declined` 收线
6. 「你这复述是不是有点挑衅了」——客户问「怎么了」，回「**怎么了**，得先确认下您是…吗？」

## 一、开场白把人问成一家店

上一轮把 `who` 从工商全称改成店铺短名后，模板仍是「请问您是{company_name}吗？」，
于是播出「您是闻溪官方旗舰店吗？」——「您」是人，宾语是店。

**官方依据**：`驳回外呼QA.xlsx` 的 52 条开头语原文确实写
「请问您是（商家公司名/店铺名称）吗？」，是电话口语的省略式；但填店铺名后
听感荒谬。赛题②环 `verify.py:2092/2108` 硬校验开场白必须含 `{company_name}`
且真跑文本含「请问您是」（"打错人是重大事故"），**不能整个删掉或改成"请问是…吗"**。

**改法**：两份场景包 GREETING 的 4 处句式统一改成
「您是{company_name}**这边**吗？」——「您这边」= 贵方，主宾对上，不预设任何职务，
也不动赛题硬校验。`reply_protest_next` 里残留的「不再提您的姓名」一并改成「不再提称呼」
（开场早已不叫姓名）。

## 二、档案里的绝对日期早就过期了

`2026-10-03` / `2026-09-09` 来自模拟档案 `recheck_deadline`，是建库时写死的固定值；
今天已是 11-12，念给商家听的是一个过去的日子。官方 56 条驳回话术里**没有任何
具体时限口径**，所以也不能换个"官方截止日"来编。

**改法**：两份场景包 9 处、`dialogue.py` 5 处代码兜底统一把
`{deadline}前完成` → `建议一周内完成`；`_fill_application` 的 `{deadline}` 映射
不再读档案，固定为「一周内」（任何残留占位符都只会得到相对口径）。新增回归测试
遍历两份配置所有字符串，断言绝无 `\d{4}-\d{2}-\d{2}`、无 `{deadline}`，
并断言真跑链 8 轮回复里也没有绝对日期。

## 三、分步话术结尾自相矛盾

`reply_help_steps` 按「第一步 / 第二步 / 第三步」讲完，却问「您想先弄哪一样，
我再细说」——顺序操作没有"先弄哪一样"。改为
「**您对哪一步还不清楚？我再细说这一步。**」（3 处 × 2 份 + 代码兜底）。
问号还顺带挡住 `persona` 的推进型后缀「这一步您清楚怎么补吗？」，避免一句里
连问两次。`_NO_TAIL_MARKS` 另加「不催您表态 / 不用您回 / 哪一步 / 还不清楚」作双保险。

## 四、客户在追问范围，系统却一路讨回应

真跑复现（川上官方旗舰店 / 闻樾）逐轮结果，与用户截图逐字对应：

```
[4] 你：这几步都要弄吗  → 官方原话「请补齐后重新提交」（没回答"都要弄吗"）
[5] 你：补齐到哪        → 「您看这样解释清楚了吗？…」  CONFIRM
[6] 你：还有疑问        → 「您这边确认下，是清楚了还是还有疑问？」ambiguous
[7] 你：你到底啥意思    → 「…回我一句『同意』或『不需要』就行」  串场
[8] 你：同意不需要啥    → 「好的，我先把您的情况记录下来…再见」  declined
```

**根因不是单点文案**：客户每次提出具体问题都被当成"没表态"。
`policy.question_class` 没有「补齐到哪」这一类 → NEED 答不上就
`next_stage="CONFIRM"` 播讨回应；`还有疑问` 被算含糊；含糊兜底写死了营销场景的
「同意 / 不需要」；`同意不需要啥` 因含"不需要"被 `classify` 判 `no`，
在 NEED 最前面的 `if flags["no"]` 直接回写 `declined` 收线。

**改法**：
- 新增 `_is_scope_question`（`scope` 问范围 / `doubt` 表达没听懂）与 `_scope_reply`，
  用本单事实正面回答（材料清单 + 三步 + 建议一周内 + 热线），
  `intent="scope_answer"` 走冻结，不许改写层把清单压成一句「您清楚了吗」。
- 拦截统一放在 `respond()` 的**所有阶段分支之前**——NEED 的 `flags["no"]` 早于
  阶段内任何分支，放阶段里拦不住 [8]。质疑优先于 `no`（客户是在问"你说的啥"）。
- `scope` / `doubt` **分别计数**，各配 3 个轮换版本，连问不逐字复读；
  第二遍换角度只讲"卡在哪一步"，第三遍升级到专员回电。
- 含糊兜底改场景无关文案，删掉「同意 / 不需要」。
- 第一问「这几步都要弄吗」：官方原话逐字保留，后面补一句
  「这几步都要走完，材料一样都不能少。」，既不破坏官方口径也正面回答了。

**两道闸（防误伤）**：只在有 `slots.application` 的资审场景生效（售后场景没有
材料清单可讲）；明确 `yes/no/hangup/deny` 不拦，只有质疑类才允许盖过 `no`。

## 五、回声复述

`agent_free._strip_echo_open` 早就防过「怎么了，得先确认您是…」，但规则状态机 /
措辞层 / 性格层都不走它。新增 `dialogue._strip_user_echo`，在 `_reply` 出口
（性格适配之后、复读判定之前）统一剥掉以本轮客户原话开头的部分；只剥句首，
句中提及不动，剩余不足 4 字不剥。

## 六、踩过的坑（如实记录）

1. 批量替换脚本把 `{deadline}前完成` 的命中数写成 6（实际 5），断言在写回前
   中止，文件未改动——修正后重跑，没有留下半改状态。
2. 测试里用 `config_loader.scene_name()` 存场景再 `set_scene(prev)` 恢复，
   但 `scene_name()` 返回中文**显示名**不是场景 id，抛 FileNotFoundError；
   改用 `scene_path()`（绝对路径）。
3. 第一版 `_DOUBT_MARKS` 收了「说啥 / 你说啥 / 没懂 / 听不懂」，把性格跑批
   **T05「听不清要重说的老师傅」**的没听清台词抢成质疑：5 轮闭环被拖成 14 轮
   不闭环，`evolve_persona.py doctor --deep` 从 12/12 掉到 11/12。收紧成
   只认「还有疑问 / 啥意思 / 到底啥…」，短句以「啥」收尾还要带"不需要/同意/到底"。
4. 收紧后 T05 仍 11/12：第二层原因是我把 NEED「答不上具体问题」的兜底也改成了
   范围回答，打断了老师傅原有的复述→闭环链。而 `补齐到哪` 已由 `respond` 层
   拦截接住，这处兜底改动是多余的 → **恢复原路径**，T05 回到 12/12。
   没有用 `evolve_persona.py init` 重定性格基线去掩盖回归。
5. 改了 `pop_reject.json`，L2 基线按惯例 `evolve.py rebase`，**v44 → v45**
   （10/10、train 7/7、holdout 3/3）。

## 八、遗留

- 赛题②环保留「请问您是 XX 这边吗」，单位名与身份确认仍靠 IDENTITY 报预留手机号
  后四位；这是与"别一上来报单位"诉求的真实取舍。
- `scope` / `doubt` 仍是词表识别，换个说法（「那几样都得交？」）可能漏；
  语义识别要接意图模型。
- NEED「答不上具体问题」的原有兜底仍是讨回应（`reply_after_ask`），
  只对未被 `_scope` 覆盖的问题生效；性格跑批 T05 的闭环链依赖它，本轮未动。
- 语音模式（插话/回声）仍未在浏览器实测；rich 话术约 200 字仍是整句 TTS。
