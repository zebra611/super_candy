### 2.2 幂等开关：没配是真的，但"等于没开"要打折

`config/scene.json` 的 `tools` 段：

```json
{"provider": "mock", "timeout_ms": 300, "base_url": "http://127.0.0.1:8100"}
```

确实没有 `idempotency_store`，`adapters.get_adapter` 于是走 `memory`。实测两种模式的差别：

```
memory   第一次 created=True  id=T67F6274E | 重启后 created=True  id=T67F6274E
sqlite   第一次 created=True  id=T67F6274E | 重启后 created=False id=T67F6274E
```

**单号在两种模式下都一样**——因为 `mock.create_ticket` 的 `ticket_id` 是由
`session_id` 做 md5 派生出来的，不是随机。所以"重启后会多出一张单"这个最坏情况
并不会发生；丢掉的只是 `created=False` 这个语义和 `version` 历史。

再加两条现实约束：
- `real` 模式的持久化在**对端**（`mock_business` 自己 `_persist_tickets()`），配了也没用；
- 线上容器没有持久卷，配了 `sqlite` 也只扛"同一容器内进程重启"。

结论：这两个 key 的价值是**答辩时能演示"重启后 created=False"**，不是为了修 bug。
加不加要 4 号点头，因为它会把 `data/tickets.db` 带进部署包——上一个事故
（docs/53）就是部署包里的 `data/events.db` 没清干净。

### 2.6 persona 判重复：比它说的更严重

它说的是"存的是加过后缀的句子，比的是没加后缀的句子"。实测证明这不只是"脆弱"，
是**整条轮换分支从来没跑过**：

```
轮1 播出: 我已经把您的情况记下来了。您也可以对照申请单编号核实。
轮2 播出: 我已经把您的情况记下来了。您也可以对照申请单编号核实。   ← 逐字相同
轮3 播出: 我已经把您的情况记下来了。                               ← 后缀被 _used 砍掉
repeat_n 三轮全是 None                                            ← avoid_repeat 从未执行
```

只要上一轮挂过后缀，`"X"` 就永远不等于 `"X您慢慢看。"`，`repeated` 恒为 `False`。
它说"现在是靠前后缀策略绕开了症状"——不够准确：症状根本没被绕开，是**掩盖了**。
`dialogue` 出口那句骨架复读兜底（`text == last_reply_text`）能接住骨架路径，
但模型路径（`_free=True`）不走那条，于是模型句 + 后缀会原样播两遍。

## 三、这次改了什么

### 3.1 代码（三处）

**(1) `modules/persona.py`：重复判定改用「上一轮的原始句」**

新增 `session["last_base_text"]`，在 `adapt` 入口写入、比对上轮的值，
**不动** `last_reply_text`（它还扛着 dialogue 的骨架复读兜底和 agent_free 的
跨轮去重，口径是"实际播出的句子"，改含义会把那两处一起弄错）。
老调用点只塞 `last_reply_text` 的，退化用它，行为与改前一致。

同时修掉一个连带问题：规则表里有三条（`skeptical` / `talkative` / `cooperative`）
的 `avoid_repeat[0]` 与 `suffix` **逐字相同**，即使判出重复也会念出同一句
（`_append` 见到已在句中的尾巴直接返回）。现在筛选掉同义项，并且重复轮用
轮换句**替代**固定后缀，而不是两者叠加——否则一句会有两个尾巴：

```
轮1 我已经把您的情况记下来了。您也可以对照申请单编号核实。
轮2 我已经把您的情况记下来了。刚才这段是官方口径，您可以再核一遍。
```

**残留**：`skeptical` 筛掉同义项后只剩 1 条轮换句，第三遍重复仍会撞同一句。
要彻底解决得给这三条规则各补 2–3 句真正不同的说法（数据层，`config/persona_adapt.json`，
归 4 号审核）。代码这层保证"至少第二次不重样"。

**(2) `modules/adapters/base.py`：没实现的工具不再抛异常**

`fn = getattr(self, method)` 原来写在 `try` **外面**。`send_checklist` 只做在
`MockAdapter` 上，切 `provider=real` 调它直接抛 `AttributeError`，绕过
`dispatch` 承诺的"失败不抛异常"，一路冒到编排层：

```
AttributeError: 'RealAdapter' object has no attribute 'send_checklist'
```

现在返回 `{"error": "UNKNOWN_TOOL", "message": "适配器 real 未实现 send_checklist", "_ms": 0.01}`，
读类工具再补 `found=False`，编排走原有兜底话术。

**(3) `scripts/verify.py` 一条断言：第二个场景换独立 session**

「客户刚给信息时不追加要信息型后缀（反向：平时照常追加）」原来在**同一个 session**
上 pop 掉 `fact_ack_turn` 再 adapt 一次。判重复修好之后，第二遍被正确判成重复并换了说法，
断言红。红的原因是"它确实是重复"，不是"后缀没挂"——这条断言测的变量被污染了。
改成独立 session 后恢复绿，**测的东西没变少，反而更纯**（原来混着"重复"这个变量）。
这一条属于我改测试，如实记在这里，不算回归。
