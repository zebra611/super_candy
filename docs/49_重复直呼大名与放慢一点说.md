# 49 · 一直重复 / 不要直呼大名 / 再见后为什么还说「我放慢一点说」

2026-11-11 深夜那通通话的三张截图复盘（11-12 完成）。用户三问：

1. 「为啥一直重复，我想要更详细的解释，请你查询相关资料，把更详细的话术补充其中」
2. 「不要直呼大名！你只确定他是负责人，怎么确定他是谁？」
3. 「最后问候语，再见后为什么还要说一句『我放慢一点说』？」

截图实录：客户连说「你能再说一遍，我根本没听清」「能不能简洁直了」「你别再重复了」
「不要再重复了，不要重复，求求你了」，客服把同一段「（未审核品牌065）品类、
商城和3C类目、营业执照经营范围未覆盖、需补营业执照/主体变更证明/店铺认证截图」
念了四遍；前端自己都弹了三次「[打断] 你的【话术重复了】」。

## 一、为什么一直重复：根因是「重复请求被当成提问」

客户说「没听清 / 再说一遍 / 简洁点 / 别重复」时，`classify` 只把它们当普通
`flags["ask"]`，于是每轮都落进 NEED/OFFER 的「回答提问」分支，查出来的还是同一句
`reply_application_detail`。骨架去重只判 `text == last_reply_text`，而每轮经过
措辞层改写后字串略有不同，去重闸识别不出来 → 客户听到的就是复读机。

### 查了哪些官方资料（用户明确要求「查询相关资料」）

- `competition/官方资料包/驳回外呼QA.xlsx` 三个 sheet（驳回话术 56 行 / 高频QA / 特殊场景）；
- `competition/官方资料包/POP计算关单场景话术V1.0.xlsx`；
- `config/kb_pop.json`（官方 96 条，含 KB-POP-034 等）。

**核对结论（必须如实写）**：截图里那条「营业执照经营范围未覆盖申请类目」**并不在**
官方 56 条驳回话术里，是模拟档案生成的演示场景。所以第一版我按常识写的
「主体变更证明是公司改名才需要」「店铺认证截图用来确认店铺身份」属于**官方无据的
业务解释**，已全部删除——不能把编出来的业务规则当官方口径讲给商家。

官方资料真正给的是两件可复用的东西：

- **四段式话术**：自报身份 → 确认单位 → 说明驳回原因 → 具体要求（补什么/怎么改）
  → 结束语（热线 4006180092 + 感谢接听）；
- **追问给增量答案**（高频QA/特殊场景）：如「这个我补上来了就可以通过了吗」→
  「您材料上传后，具体是否通过，我们会在审核您完整的材料后才可以确定，
  如果有问题也会再次联系您的」；「在哪里修改」→ 后台具体路径。

### 落地

新增 `_re_explain`（`modules/dialogue.py`），排在 help_seek 之后、含糊/情绪/提问之前：

- 客户说**没听清/再说一遍** → `reply_application_detail_rich`：按官方四段式把
  本单事实（档案真值 `{application_desc}/{reason}/{materials}/{deadline}`）、
  三步操作、结果口径、热线兜底一次铺开，**走 `intent=explain_detail` 冻结**。
  不冻结会被 nlg 改写层压成一句「原因是XX」（验证实测：材料清单和热线全丢），
  客户还是没听清，下一轮继续复读，等于白改。
- **第二遍起换角度** → `reply_application_detail_rich_2`：只讲「接下来怎么办」
  （操作步骤/结果口径/热线），不再复述原因和材料清单。详细 ≠ 把同一段念得更长。
- 客户说**简洁/别重复/直说** → `reply_application_detail_short`：认账 + 一句干货 + 热线。
- 费用/有效期/怎么提交等**有专门答案的问题**经 `_re_explain_defer` 放行，
  不抢成重述驳回原因。

**踩过的坑（Q2 课程自检抓到的真回归）**：第一版 `_re_explain` 没有场景闸和表态闸，
售后「听不清」画像 EV17-20 第 7 轮「我这边听不清**但同意了**」被抢成解释，
同意没被接住，闭环从 40/40 掉到 36/40。修法两道：

- **场景闸**：这套话术讲的是资质申请单，只在 `slots.application` 真有档案时成立；
- **表态闸**：`flags` 里 yes/no/hangup/deny 任一为真，一律不拦（「但同意了」是同意）。

回归测试 `scripts/test_repeat_explain.py` 里两条对应断言守着，防再犯。

## 二、不要直呼大名：开场白只确认单位，不预设身份

放大截图逐字核对，开场白是：

> 您好，我是京东商家资质审核专员，请问您是**新疆维吾尔自治区溪亭商贸有限公司**
> 的**品牌授权经办人**吗？

没有叫客户姓名（晚四 `_drop_name_call` 已修），但**一上来就报了超长工商全称，
还预设了「品牌授权经办人」这顶身份帽子**。客户只要回一句「嗯，是的」就被当成
认过了——这正是「你只确定他是负责人，怎么确定他是谁？」。

**赛题硬约束**：四段式第②环「确认对方身份（请问您是 XX 公司吗）不能省，
打错人是重大事故」，`scripts/verify.py:2092/2108` 明写两条断言；官方 52 条话术
固定格式也是「请问您是（商家公司名/店铺名）…吗？」——**带单位名**。
所以单位名不能整个删掉，否则把防打错人的闸门拆了。

对照官方原文后的发现：官方格式里**根本没有「的XX职务」**，`{contact_role}` 是
我们自己加的。落地（两份场景包同步）：

- 去掉全部 4 处 `的{contact_role}` → 「请问您是{company_name}吗？」；
- `_fill_outbound` 的 `who` 从 `name or shop or short` 改为 **`shop or name or short`**：
  优先店铺名（「美孚官方旗舰店」，官方允许「店铺名」，且短、听着自然），
  不再念「新疆维吾尔自治区…有限公司」整串；
- 真正「确定他是谁」靠 **IDENTITY 阶段报预留手机号后四位**（截图里的 9326），
  核身通过前不讲申请单详情（`reply_ask_before_identity` 守着）。
  开场白只负责「找对单位」，不负责「认出这个人」。

`{contact_role}` 占位符本身保留在 `_fill_outbound` 里做兜底替换（旧场景万一还带），
绝不把花括号念给客户听。

## 三、再见后为什么还挂「我放慢一点说」

两句根因，都在「收线话术没被当成收线」：

1. `persona.py` 的 `hard_of_hearing` 规则后缀是「我放慢一点说。」，
   收线句不在 `_NO_TAIL_MARKS` 里，于是被挂到「感谢您的接听，再见。」后面；
2. `_stage_done` 里答不上问题时的热线兜底调 `_reply(..., intent="ask")`
   **没带 `next_stage="DONE"`**，DONE 冻结根本没生效。

修法（三层，都带反向对照防假绿）：

- `_NO_TAIL_MARKS` 加「感谢您的接听」。**只加这一条、不加「再见」**：
  `test_scene_isolation` 的对照组用「感谢您的配合，再见。」验证非 DONE 上下文
  性格确实会加后缀，把「再见」收进去会误伤它，让那条断言变成假绿。
- 热线兜底两句加 `next_stage="DONE"`，并把 intent 换成新的冻结 intent
  `hotline_close`。这一步是测试逼出来的：`intent="ask"` 会进改写层，把
  「您也可以拨打热线 / 感谢您的接听」改成「欢迎拨打热线 / 感谢接听」——
  措辞一变，收线标记匹配不上，尾巴又会挂回来。官方热线口径改为逐字播出。

## 五、仍留着（不粉饰）

- rich 话术整段约 200 字，TTS 仍是整句合成；要真压到 1 秒内需流式。
- 「没听清 / 简洁 / 别重复」仍是词表识别，靠场景闸 + 表态闸兜住误伤，
  不是语义理解。
