# 47 · 三张截图说"还是不智能"：客服听不懂人话的四类根因

2026-11-11 深夜。用户连发两张截图加一段事件日志（还有一张此前已修的），结论一句："还是不是很智能。"

逐轮读完三份材料，问题不是同一个，但根因高度收敛——**客服把"回答"当成"噪声"，把"抗议"当成"拒绝"，把"求助"当成"没听清"**。这一轮改的全是"听懂"这一层，不是话术打磨。

## 二、四类根因与修法

### ① 求助 ≠ 含糊（最核心）

客户答"不清楚"是对"您清楚怎么补吗"的**回答**，答案是"我不会"。旧逻辑把它和"嗯""啊"一起塞进含糊梯子：反问 → 复述 → 收线。

新机制（`_help_reply`，三段，全程不复述已说过的事实）：

1. **第一次**：给分步操作——准备好哪些材料 → 登录商家后台在哪上传 → 什么时候提交完；
2. **第二次**：升级——材料清单和操作步骤发到商家后台 + 专员用官方号码回电带着弄，工单记 `callback_needed=true` / `merchant_understood=false`；
3. **第三次**：干脆收尾，最后一句把升级承诺再说完整，`end_reason=help_escalated`。

判据 `_is_help_seek`：求助词（不清楚/不知道/搞不懂/咋补/怎么弄…）即求助，**不要求上一轮问过引导问句**（线上实测：NEED 解释完事实客户就答"不清楚"，没有问句上下文）。**只在资审场景生效**——营销/售后场景的"咋弄"是"怎么领取"这类合法提问，走原提问链路（88 条评测 D05 方言用例抓的正是这条回归）。

CONFIRM 环节放宽：那里说"不清楚"永远是"需要帮助"，分支排在 `NOT_CLEAR_MARKS` 之前（旧路径"复述第二遍→转专员"整段退役）。

### ② 抗议称呼 ≠ 拒绝

"不要喊我名字！"带否定词，旧逻辑落到拒绝分支直接收线回写。新增全局拦截 `_is_name_protest`：道歉 + 承诺不再称呼 + 回到当前环节的正事，阶段不动、`session["no_name_call"]=true`。模型层的 prompt 在该标记下追加特别提醒（连道歉复述名字都不行），`_drop_name_call` 继续在出话后兜底。

### ③ 语言不通 ≠ 没听清

新增 `_language_reply`：第一次如实承认"只能用普通话"并用中文再说一遍重点；第二次如实转专员（`end_reason=language_barrier`），绝不装听不清、更不会答"产品使用还是售后"。

判据 `_is_foreign_lang` 有两道闸：拉丁字母明显多于汉字，**且**带问号或明确提到语言（english/中文/听不懂…）——后者是为了不把 "OK, thank you" 这类英文环境音（C6 N03）当成客户求助，噪声测试 7/7 不回归。

顺带：pop 场景的澄清兜底话术全部换成贴场景的版本，售后场景残留的"产品使用还是售后"从 CLARIFY_TEXTS 与两份场景包的 fallback 里清掉（注意 JSON 里 fallback 区与顶层各有一份键，两处都要改）。

### ④ 英文报数 = 数字

`_normalize_spoken_digits`：整句都是英文数字词时直接换算（"four four two seven" → 4427），下游意图识别、核身匹配照常工作。只处理整句都是数字词的情况，"can you speak english" 不误伤。

### ⑤ 两类重复同时堵

- **同一问句只问一次**：`_reply` 统一出口检测句末的"您清楚怎么补吗/清楚了吗"，置 `advance_ever_asked`；persona 的推进型后缀见标记就不再挂，agent_free 新增 2b 闸 `repeat_advance_question` 直接拒（骨架由规则层自己决定）。
- **鹦鹉学舌**：`_strip_echo_open` 删掉句首与客户原话相同的部分（"怎么了，得先确认…" → "得先确认…"）。

### ⑥ 赶时间给短版

`facts_spoken` 在 NEED 解释轮播完即置位；之后客户说"时间有点急/长话短说/说重点"，直接回"补{materials}，在商家后台重新提交，{deadline}前完成"，不再把驳回原因整段念第二遍。`{deadline}` 占位符补进 `_fill_application` 与配置校验白名单。

## 三、精度承诺的冻结面

求助步骤、升级承诺、抗议道歉、语言说明、赶时间短版——每一句都是**承诺**（发清单/回电/不再称呼），模型换个说法把承诺改丢比说错话更糟。这批 intent（`help_steps/help_escalate/name_protest/language_barrier/hurry_short`）进 `_FREEZE_INTENTS`，模型与措辞层都不碰，骨架原样播。

## 五、本轮没做的

- **信息倾倒**（日志 turn 3：核身+感谢+原因+三样材料一口气 60+ 字）没拆。拆句要动 TTS 分段节奏和阶段推进设计，单独一轮做。
- **模型复述事实第三遍**（川上 turn 6 "行"之后）：repeat 闸 0.75 相似度没拦住换词复述。收紧阈值会误伤，需要换判据（按事实要素计数而不是字面相似）。
- 英文语音报数（真实 ASR 音频）没测过，文字链路已通。
- 对抗集三条老面孔（AD02/AD03/L912）原样。
