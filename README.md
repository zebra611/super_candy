# super_candy

宇宙无敌超级棒棒糖！

「智语外呼」赛题的哑链路骨架：先把"一通电话"从浏览器打通到事件库，四个人再各自替换其中一段。

**当前状态：骨架，不可用于演示答辩。** 语音识别、对话编排、业务工具全部是占位实现，唯一真实的是事件流。

---

## 怎么跑

不需要装任何第三方包，Python 3.9 以上即可。

```bash
cd super_candy
python app.py
```

打开 http://127.0.0.1:8000 ，点「开始通话」，然后：

- **有麦克风**：点「按下说话」→ 说一句 → 再点一次「停止并发送」
- **没麦克风**：直接在下框打字，点「发送」

每说一轮，状态机会往前走一格：`GREETING → IDENTITY → NEED → OFFER → CONFIRM → WRITEBACK → DONE`。
走到 `WRITEBACK` 那一轮会真的调用一次 `create_ticket`，事件库里出现 `writeback` —— 这就是"闭环"的硬证据。

换端口：`python app.py 9000`

## 验收清单（搭完骨架应该全绿）

- [x] 一条命令启动，无第三方依赖
- [x] 点「开始通话」能在浏览器听到声音（浏览器自带 TTS 播报）
- [x] 六个环节能一路走到底，走到回写时真的建出工单
- [x] 事件库里能查到这通电话的完整事件链（页面右下角「事件链」面板）
- [x] 时延有数字（P50 / P95 / 每轮拆解）
- [x] 各模块能独立替换，接口不动

## 文件地图：谁该改哪个文件

| 文件 | 归属 | 现在是什么 | 你要换成什么 |
|---|---|---|---|
| `contracts.py` | **禁改区** | 事件类型、状态机阶段、工具签名 | 只许追加，不许改语义 |
| `events.py` | 角色 4 | **真实现**（SQLite 事件流） | 加索引、连接池、归档策略 |
| `config/scene.json` | 角色 4 | 占位话术 | 换成企业资料包里的真实话术与禁语 |
| `config_loader.py` | 角色 4 | 读配置 | 加多场景切换与 schema 校验 |
| `modules/voice.py` | 角色 1 | 假 ASR、假 VAD、前端播报 | 接流式 ASR/TTS、真 VAD、打断 |
| `modules/dialogue.py` | 角色 2 | 每轮推进一格的状态机 | 意图识别、槽位填充、多轮纠错 |
| `modules/tools.py` | 角色 2 / 4 | 假客户库、幂等回写 | 接企业 Mock 接口（幂等逻辑可留） |
| `modules/eval.py` | 角色 3 | 只判"有没有闭环" | 质检报告、评测集、归因、进化闭环 |
| `app.py` | 角色 4 | HTTP 路由 + 串链路 | 换 WebSocket/WebRTC，音频改流式 |
| `web/index.html` | 角色 1 | 录音、字幕、指标面板 | 换成 WebRTC，加实时字幕与打断按钮 |

改 `contracts.py` 的流程：提 PR → 全员同步 → 通知另外三个人改自己那侧。

## 接口（前端与后端之间）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/call/start` | 开一通电话，返回 `session_id` |
| POST | `/api/turn` | 一轮对话，体 `{session_id, text?}` 或 `{session_id, audio_b64}` |
| POST | `/api/call/end` | 挂断 |
| GET | `/api/events?session_id=` | 这通电话的事件链 |
| GET | `/api/report?session_id=` | 转写 + 质检 + 打分（角色 3 的入口） |
| GET | `/api/metrics` | 全局 P50 / P95 / 闭环数 |
| GET | `/api/health` | 存活检查 |

## 已知的"假"

这些是刻意留的，不是 bug：

1. **不认识你说的话**。`voice.asr()` 不管你上传什么音频，都返回同一句固定文本。所以"多轮纠错""主动追问"现在全靠状态机硬推。
2. **不查订单就问体验**。`NEED` 阶段应该先 `query_order` 再问，现在直接问。
3. **播报是浏览器念的**，不是我们的 TTS。服务端 `tts()` 只回一个指令。
4. **不会被打断**。`detect_barge_in()` 恒为 False，音频是整段上传不是流式。
5. **质检分数是占位公式**。`compliance_report()` 只判"有没有闭环 + 有没有禁语"，其余标 `skipped`——宁可显示未检测，也不假装检测过了。
