# super_candy

宇宙无敌超级棒棒糖！

「智语外呼」赛题的外呼数字员工：把"一通电话"从浏览器打通到事件库，再由 5 个人各自替换其中一段。

**当前状态：可运行、可评测、可演示，但语音仍是占位实现。**
真 ASR/TTS、流式与打断、WebSocket/WebRTC 还没做——这四块是 1 号的活。
其余部分（事件流、状态机、回写与改口、质检、时延双口径）已经是真实现。

---

## 30 秒上手

双击项目根目录的 **`启动.bat`** → 浏览器自动打开 `http://127.0.0.1:8000` → 点「开始通话」。
零第三方依赖，Python 3.9 以上即可。关掉黑窗口就是停止服务。

> **不要双击 `web/index.html`**：它需要后端才能工作，双击打开只会看到一堆失败的请求。
> 正确入口永远是 `http://127.0.0.1:8000`。

线上固定链接（发给老师/队友，谁点都能开）：
**https://voice-agent-skeleton.app.workbuddy.host/?sharecode=ACYOJRLVUP**

三种跑法的差别、Codespaces 怎么开、线上有哪些限制 → **[docs/10_运行与访问方式.md](docs/10_运行与访问方式.md)**

## 现在能做什么

- **六环节能走完**：开场自报身份 → 身份核验 → 需求 → 权益 → 确认 → 结构化回写，走到回写真的建工单。
- **说得含糊不会被当成拒绝**：追问一次，仍含糊才记 `unknown`；用户改口会更正同一张工单。
- **拒绝也回写**：业务侧要知道这通电话的结果，没谈成也要留痕。
- **沉默不会被当成说话**：记 `no_answer`，追问一次，连续两次才挂断。
- **合规命中即整句替换**，不打码；发布前再过一道护栏。
- **质检报告逐项给结论**：闭环、辱骂、虚假承诺、诱导、隐私泄露、必说话术，判不了的标 `skipped`。
- **时延双口径**：服务端处理耗时 + 浏览器实测首字响应（T4−T0）。

一句话验证：`python scripts/verify.py`（22 条断言）和 `python scripts/run_eval.py`（30 条用例）。

## 还是假的

真 ASR、真 VAD、服务端 TTS、打断、流式传输、真实 Mock 接口、语义级合规、RSI 自进化。
逐条列在 **[docs/14_接口与代码地图.md](docs/14_接口与代码地图.md)** 第 3 节，写明了影响和谁负责。

**评测的 30/30 不能拿去汇报。** 用例与规则是互相照着写的，成因见 `docs/06` 第 7 节。
